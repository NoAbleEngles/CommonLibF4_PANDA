# НЕМЕДЛЕННЫЕ ДЕЙСТВИЯ - ЧИТАТЬ СНАЧАЛА!

## Проблема
Visual Studio пытается использовать конфигурацию "vs2019-windows-vcpkg" вместо "vs2022-windows-vcpkg".

## Решение (выполните ПО ПОРЯДКУ):

### Вариант 1: Через Visual Studio (РЕКОМЕНДУЕТСЯ)

1. **ЗАКРОЙТЕ Visual Studio** полностью (закройте все окна VS)

2. **Откройте папку заново**:
   - Запустите Visual Studio
   - Файл → Открыть → Папка
   - Выберите папку проекта `CommonLibF4_PANDA`

3. **Выберите правильную конфигурацию**:
   - В верхней панели инструментов найдите выпадающий список конфигураций
   - Выберите **"vs2022-windows-vcpkg"** вместо "vs2019-windows-vcpkg"
   - Если его нет в списке, нажмите "Управление конфигурациями..." и выберите из доступных

4. **Удалите кэш и перенастройте**:
   - Проект → Удалить кэш и перенастроить
   - (Project → Delete Cache & Reconfigure)

5. **Подождите завершения конфигурации CMake**
   - В окне вывода должно появиться сообщение о успешной конфигурации

### Вариант 2: Через командную строку (если VS не помогает)

1. **ЗАКРОЙТЕ Visual Studio**

2. **Запустите `reconfigure_vs2022.bat`**:
   - Дважды кликните на файл `reconfigure_vs2022.bat` в корне проекта
   - ИЛИ откройте PowerShell/CMD в папке проекта и выполните:
     ```
     reconfigure_vs2022.bat
     ```

3. **Дождитесь завершения** (может занять несколько минут на первой сборке)

4. **Откройте Visual Studio** и папку проекта

## Проверка успеха:

В окне вывода CMake (View → Output → Show output from: CMake) должно быть:
```
-- The C compiler identification is MSVC 19.44.xxxxx
-- The CXX compiler identification is MSVC 19.44.xxxxx
```

И НЕ должно быть:
```
CMake Error: Generator Visual Studio 16 2019 could not find any instance of Visual Studio.
```
