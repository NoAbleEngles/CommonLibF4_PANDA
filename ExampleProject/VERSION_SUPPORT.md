# Поддержка версий Fallout 4

Этот проект поддерживает компиляцию для двух основных версий Fallout 4:

## Original Game (OG) - версии 1.10.163 и ниже

**По умолчанию**, проект компилируется для оригинальной версии игры.

Поддерживаемые версии: **1.10.162 - 1.10.163**

## Next-Gen (NG) - версии 1.11+ 

Для компиляции под Next-Gen версию игры:

Поддерживаемые версии: **1.11.191 и выше**

### Способ 1: CMake опция (рекомендуется)

При конфигурации проекта через CMake:

```bash
# Для OG версии (по умолчанию)
cmake -B build

# Для NG версии
cmake -B build -DF4_SUPPORT_NG=ON
```

Или в CMake GUI:
- Найдите опцию `F4_SUPPORT_NG`
- Установите значение `ON` для Next-Gen версии

### Способ 2: Макрос в main.cpp

Раскомментируйте макрос в начале файла `src/main.cpp`:

```cpp
// Раскомментируйте эту строку для NG версии
#define F4_SUPPORT_NG
```

### Способ 3: Compiler Flags в Visual Studio

В настройках проекта:
- Properties → C/C++ → Preprocessor → Preprocessor Definitions
- Добавьте: `F4_SUPPORT_NG`

## Различия в поведении

### OG версия:
- Проверяет, что версия >= 1.10.162 и <= 1.10.163
- Логирует: `"detected Original Game runtime v{version}"`
- Отклоняет загрузку на версиях 1.11+

### NG версия:
- Проверяет, что версия >= 1.11.191
- Логирует: `"detected Next-Gen runtime v{version}"`
- Работает с Next-Gen обновлениями игры

## Примечание

API загрузки F4SE (`F4SEPlugin_Query` и `F4SEPlugin_Load`) остается одинаковым для обеих версий в текущей реализации CommonLibF4. 

В будущих версиях могут быть добавлены специфичные для NG механизмы загрузки, такие как `F4SEPlugin_Preload` или декларация версии через `F4SEPlugin_Version`.
